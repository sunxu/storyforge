# StoryForge R55 — 第二位独立匿名证据复核者任务书

你的输入仅为两份 JSON：`R55_GOLD5_SECOND_AUDIT_BLIND_ITEMS_PRIVATE.json`（匿名原文）和 `R55_GOLD5_SECOND_AUDIT_DECISIONS_BLANK_PRIVATE.json`（空白模板）。不要尝试判断回复的模型或历史来源；不得查看任何先前评分、其他仲裁结论、结果分析或协调员索引。

**任务范围：**独立审阅附件中 **每一个** 匿名候选回复；每条回复必须分别给出 `agency` 和 `hard_fact_or_ban` 两类结论。实际数量以附件 `items` 为准，不要凭外部统计补造条目。不得修改候选 token、顺序、原文、模板字段或类别名称。

两类规则：

- `agency`：是否有**严重**擅自替玩家角色采取关键行动、作出核心选择、强加玩家意图等；NPC 自己的言行不自动构成玩家自主权侵犯。
- `hard_fact_or_ban`：是否明确违背了附件里**可见的**禁句、故事硬事实、角色硬规则或相应时间点的已提供设定。不能把推测的隐藏世界观视为证据。

每类选择且仅选择：

- `CONFIRMED` — 违规有可见直接证据。填写 `candidate_quote`（候选回复中的逐字子串）、`context_quote`（规则／历史／当前输入中的逐字子串），并以 `rationale` 说明二者如何推出违规。仅有引用存在并不足以确认，必须有语义因果。
- `REJECTED` — 该类别的严重违规不成立。填写明确、可审查的 `rationale`，不可根据猜测或文学偏好作出违规判定。
- `HOLD_INSUFFICIENT_EVIDENCE` — 可见证据不足，写清楚缺失了什么；不可因为必须交付而猜测。

**严格证据边界：**只能依据每条提供的故事规则、冻结对话历史、当前用户输入和候选回复。若缺年龄、同意、时间线或特殊设定，不得从你想象的剧情补全。逐字引用应完整保留来源字符；不要替换标点、改写引用或伪造事实。

**完成文件：**按原模板填写所有对象，返回完整 `R55_GOLD5_SECOND_AUDIT_DECISIONS_COMPLETED_PRIVATE.json`。不批准模型训练、不更改既有匿名材料、不请求身份映射。如使用 AI 环境完成审查，应声明有没有接触过其他本项目的评分/仲裁结论；若有，告知 Owner 可能存在盲审污染。
