# StoryForge R47 — 匿名三回复独立评审指南

**盲审范围：20 组互动小说 / 角色扮演测试。每组有相同背景、前文与玩家输入，及匿名回复 A/B/C。**

## 必读规则

你只评估材料中的 A/B/C 回复质量，不需要也**不应猜测模型身份**，更不能要求答案对应信息。整个评审过程中，不查看其他评审者评分、不查阅旧版历史评分或仲裁结论、不使用 ChatGPT 之外或材料之外的“故事设定猜测”替代原文证据。按 CSV 给出的原始背景、前文和当前玩家消息判断。

每份 CSV 共 **20 行**。请完整评审 20 行，**不要改动** `样本编号`、背景、历史消息、玩家输入、回复 A/B/C 的原文，也不要删改、插入或重排行。

## 六个维度（每个匿名回复分别 1–5 分）

| 维度 | 重点 |
|---|---|
| 剧情连续性 | 事件时序、地点、身份、关系、已知事实是否一致 |
| 角色一致性 | 人物说话与行动是否符合提供的设定与前文状态 |
| 指令遵循 | 是否遵守此前约定、当前玩家指令和长期禁令 |
| 文学表现力 | 语言自然、细节具体、风格契合、不重复不空泛 |
| 互动推进 | 能让故事继续推进，但不强行替玩家作主 |
| 玩家自主权 | 不代写玩家未说的话、不擅自决定玩家的意志或行动 |

**评分尺度：** 5=非常好且证据明确；4=较好、有轻微瑕疵；3=可用、有明显问题；2=较差、有严重或多处问题；1=不可接受或明显违背核心约束。允许同分，也允许 A/B/C 表现都不好。不要只根据文笔华丽给高分。

## 每条样本必须完成的内容

1. `整体最佳(A/B/C/TIE)`：填写 A、B、C，或在确实无法判定唯一最佳时填写 TIE。
2. `评分理由与逐字证据`：至少写出支持评分的、能够在原文逐字定位的引用；区分回复错误与评审者的主观写作偏好。必须有足够文字说明，不接受简单“更自然”等空泛结论。
3. `严重问题与对应回复`：如有则点名 A/B/C 和对应原文字句；如没有，明确填写 `无`，不可留空。
4. `玩家自主权严重侵犯(A/B/C/无)`：填写触发严重侵犯的回复字母；如无填写 `无`。若多个回复均触发，在“严重问题与对应回复”列逐个列明，且该列只能填写一个字母或“无”，则在本字段标出最严重者。
5. **18 个维度评分格**：六维 × A/B/C 每个都填 1–5 的**整数**，没有理由可以跳过的空项。

## 审查时重点排雷

特别检查是否无依据新增世界事实、错认身份/关系、遗忘先前命令、强迫玩家角色行动或说话，以及角色动机和故事推进是否自洽。涉及价值判断或内容边界时，要基于原文和评价标准评述，不任意改写故事，也不添加原文没有的证据。

先独立完成所有 20 组，再把**你自己的已填写 CSV** 交回协调员。不要发布模型身份猜测、在群聊透露偏好、索取其他评审人的表格或擅自修改原始盲审回复。

本评审是一个已经用于历史回归分析的题组，仅判断这些已知测试题上的质量。**它不是全新独立 Held-out，也不能单独证明模型应获正式晋升。**
