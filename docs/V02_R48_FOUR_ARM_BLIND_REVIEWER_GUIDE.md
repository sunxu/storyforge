# StoryForge R48 — 四回复匿名独立评审指南

**评审对象：20 组互动小说/角色扮演测试，每组包含原始世界背景、历史、玩家输入和匿名回复 A/B/C/D。**

## 必须遵循

- 只根据每一行提供的故事文本与匿名四份回复判断质量，不猜测或询问任何回复的生成者、来源或模型身份。
- 禁止查看此前任何一轮评审得分、结论、争议处理、其他评审者评分或答案映射。
- 完成全部 20 行；**禁止修改** `样本编号`、背景、历史、玩家输入和回复 A/B/C/D；不得删除、增加或调换行。
- 相同样本中四个回复都可能存在错误，没有任何一个回复天然正确；选择最优者时仍应对其缺陷扣分。
- 四份回复的 A/B/C/D 位置会逐条重新随机化；不可假定一个字母始终对应同一来源。

## 六维评价，每个回复独立打分（1–5 整数）

| 维度 | 评审重点 |
|---|---|
| 剧情连续性 | 时序、事件、世界设定、已发生状态无矛盾 |
| 角色一致性 | 身份、立场、说话方式、关系和动机符合已知证据 |
| 指令遵循 | 当前消息与历史长期约定、禁止台词和情境限制均遵守 |
| 文学表现力 | 文字自然、有细节、符合场景情绪、不循环堆砌 |
| 互动推进 | 推进 NPC 行动和有意义的下一轮悬念，不强制玩家做决定 |
| 玩家自主权 | 不替玩家确定未声明的意图、内心、对白、行动和承诺 |

分数：5=非常优秀，4=良好，3=可用但明显有瑕疵，2=较差，1=核心违约/不可接受。同一项允许并列得分。

## 每行必须填写

- `整体最佳(A/B/C/D/TIE)`：只能填 A/B/C/D 或确实无法选出唯一最佳时的 TIE。
- `评分理由与逐字证据`：对四份回复的优势和缺陷说明理由，至少给出来自原文可定位的证据。不推测故事外设定。
- `严重问题与对应回复`：指出严重违背事实/长期禁令/玩家自主权的回复与原文；无严重问题填写 `无`。
- `玩家自主权严重侵犯(A/B/C/D/无)`：无则填 `无`，多个则按字母顺序写 `A,C` 等，无空格。
- **24 个评分格**：六维 × 四份回复，各填一个 1–5 整数。

硬性禁令不能靠文笔分抵消；同时避免把角色自己的暴力、威胁等戏剧性行为一概误判为玩家自主权被剥夺。关键在于回复是否替玩家执行、确定或预设了其尚未选择的行为与心理。

若相对最佳回复仍有严重问题，应同时保留最佳选项和严重问题标记，不得为了看起来一致而隐藏事实。

评完后只把你自己的 CSV 交给评审协调员，未经收齐全部评审不得互相讨论或交换结果。**本轮是历史题组回归诊断，不是全新独立 Held-out 或正式模型晋升依据。**
