## Four-arm grading

Give each of **three genuinely independent reviewers** a different R48 CSV, together with the completely identity-free [R48 reviewer guide](V02_R48_FOUR_ARM_BLIND_REVIEWER_GUIDE.md). Never share the coordinator directory, model identities, Gold/reference provenance, old R47 finished review sheets or historical R47 report with reviewers. Prefer reviewers who have not seen the previously unblinded R47 results.

Each reviewer scores each of the 20 items in six dimensions, across A/B/C/D: **24 integer 1–5 scores per item**, overall A/B/C/D/TIE preference, source-anchored written reason and severe problem flag. Total **1,440** ratings (3×20×4×6).

After independent review, preserve originals and place the three **completed** CSVs into a new private folder, for example `$HOME/.local/share/storyforge/r48/ratings-r01/`. Do not overwrite the blank source sheets. **Before** reading the answer key, run:

```bash
R48="$HOME/.local/share/storyforge/r48/r48-20261014-gold-four-arm-20"
REV="$HOME/.local/share/storyforge/r48/ratings-r01"
python3 scripts/v02_r48_review_aggregate.py \
  --manifest evaluations/v0.1/test/manifest.json \
  --pristine-dir "$R48/reviewers" \
  --reviews "$REV/R48_Reviewer_01_completed.csv" \
    "$REV/R48_Reviewer_02_completed.csv" \
    "$REV/R48_Reviewer_03_completed.csv"
```

Expected `R48_THREE_REVIEWERS_20_CASES_1440_RATINGS_COMPLETE_KEY_NOT_READ`. The script verifies every original input and anonymous answer field still matches the pristine R48 blank reviewer exports, all 20 source IDs and all 1,440 scores. Does not access the private mapping.

Only after all three scored sheets have been frozen may the coordinator unblind:

```bash

  --pristine-dir "$R48/reviewers" \

  --output "$REV/R48_PRIVATE_UNBLIND_DIAGNOSTIC.json"
```

Expected status `R48_GOLD_FOUR_ARM_RETROSPECTIVE_UNBLIND_NOT_PROMOTED`. Compare raw model preferences, **20** three-reviewer case majorities, all six mean dimensions, serious-agency errors, Gold issue rate, and sample-level disagreements.

## Scientific and privacy limits

- All 20 cases are **previously exposed v0.1 old Test questions**; they are not fresh independent Held-out. Do not use R48 results to authorize model-quality promotion or training data admission.
- Comparisons use the same prompts and replies, but **original Gold may come from a human/source editorial process**, not identical generation conditions. Gold is a quality reference and is not a fourth AI model.
- R47 and R48 votes come from different candidate sets and (ideally) independent reviewer rounds; do not merge/reweight them. Four-option preference is not a pairwise win rate.
- Report important long-term hard ban and player-autonomy failures for **all four arms**, including original Gold.
- The original story texts in the local review package and private answer key **must remain private**. Do not commit R48 coordinator keys or raw 80-response CSVs by default. Avoid uploading an owner-specific local/private file into Git without careful privacy review.
- Independent, newly written and sealed 40–60 Held-out cases from ≥4 unused story-world components are still needed for final v0.2 promotion.
